COMMANDER – START HIER

WICHTIG:
Die App ist bereits mit deinem Supabase-Projekt verbunden.
Der eingetragene Publishable Key ist für Browser-Apps vorgesehen.
Keinen Secret-Key und keinen service_role-Key in die App eintragen.

SCHRITT 1 – DATENBANK EINRICHTEN
1. Öffne dein Commander-Projekt bei Supabase.
2. Öffne links den SQL Editor.
3. Öffne in diesem Ordner die Datei:
   supabase-setup.sql
4. Kopiere den kompletten Inhalt in den SQL Editor.
5. Drücke auf RUN.
6. Es sollte anschließend kein roter Fehler angezeigt werden.

SCHRITT 2 – APP BEI NETLIFY HOCHLADEN
1. Diesen ZIP-Ordner zuerst entpacken.
2. Bei Netlify deinen bisherigen Deploy öffnen.
3. Den entpackten Ordner bzw. alle enthaltenen Dateien hochladen.
4. Wichtig: index.html muss direkt im hochgeladenen Hauptordner liegen.

SCHRITT 3 – SUPABASE URL EINTRAGEN
Nachdem Netlify die App veröffentlicht hat:
1. Kopiere deinen vollständigen Netlify-Link.
2. Öffne Supabase:
   Authentication → URL Configuration
3. Trage bei Site URL deinen Netlify-Link ein.
4. Füge bei Redirect URLs ebenfalls den Netlify-Link ein.
   Am besten zusätzlich: https://DEINE-SEITE.netlify.app/**

SCHRITT 4 – ERSTES ADMIN-KONTO
1. Öffne die App.
2. Registriere dich mit:
   vapeofdarkside@gmail.com
3. Wähle selbst ein Passwort.
4. Bestätige gegebenenfalls die E-Mail von Supabase.
5. Dieses Konto wird automatisch als Admin und Team Leader freigeschaltet.

MITGLIEDER
- Registrieren sich mit eigener E-Mail und eigenem Passwort.
- Neue Mitglieder bleiben zunächst auf „Freigabe ausstehend“.
- Du siehst sie unter Team → Freigaben.
- Mitglieder können nur Ja/Nein abstimmen und ihre eigenen Skillpoints sehen.
- Nur Admins können Spieltage, Mitglieder, Rollen und Skillpoints bearbeiten.

IPHONE
Safari → Teilen → Zum Home-Bildschirm.
